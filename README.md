# Book Management API

## Overview

A simple REST API for managing books using Spring Boot, Spring Data JPA and MySQL.

## Technologies

- Java 17
- Spring Boot
- Spring Web
- Spring Data JPA
- MySQL
- Maven
- Git
- GitHub
- Postman

## APIs

| Method | Endpoint | Description |

|---|---|---|
| POST | /books | Create a book |
| GET | /books | Get all books |
| GET | /books/{id} | Get book by ID |
| DELETE | /books/{id} | Delete a book |

## Architecture

Controller → Service → Repository → MySQL
